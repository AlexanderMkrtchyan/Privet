# Linux packaging

Built by `scripts/build-linux.sh`:

- `server/public/downloads/privet-linux-x64.tar.gz` — portable bundle
- `server/public/downloads/privet-linux-amd64.deb` — Ubuntu/Debian package (`sudo apt install ./privet-linux-amd64.deb`)
- Local install under `~/Apps/privet` plus a desktop menu entry
