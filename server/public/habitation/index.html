Habitation Activity

Трекер активного окна на Linux и Windows. Логи шифруются у тебя, на сервер уходит только ciphertext. На телефоне Habitation показывает отчёт.

Linux Windows Ключи Нужен ли venv?

Короткий ответ про Python environment

Активировать venv руками не нужно.

  • setup_linux.sh / setup_windows.bat сами создают папку .venv и ставят зависимости.
  • Агент в фоне запускается как .venv/bin/python … (Linux) или .venv\Scripts\python.exe … (Windows) — без source activate.
  • Отчёт тоже: либо ./refresh-report.sh, либо полный путь к python внутри .venv.
  • source .venv/bin/activate можно, если хочешь писать коротко python viewer/report.py — это удобство, не обязанность.

Одинаковые ключи на всех устройствах

В конфиге и в Habitation (Ещё → Компьютер) должны совпадать:

  • sync_token — доступ к серверу
  • passphrase — ключ шифрования (сервер его не знает)
  • api_base — обычно https://messenger.banderdog.com

Не публикуй passphrase. Потерял — старые отчёты не расшифруешь.

Linux

Ubuntu / GNOME. Один раз настроил — агент сам стартует после входа в систему.

Скачать

Скачать ZIP для Linux Инструкция текстом

Распакуй, например, в ~/habitation-activity. Если репозиторий Habitation уже есть — можно сразу работать из папки habitation/activity.

Шаг 1 — что должно быть в системе

  1. python3 и python3-venv
  2. пакеты для чтения активного окна на GNOME Wayland (обычно уже стоят):
sudo apt update sudo apt install -y python3 python3-venv python3-gi gir1.2-atspi-2.0 python3-dbus

На GNOME один раз включи accessibility (агент без этого часто не видит окно):

gsettings set org.gnome.desktop.interface toolkit-accessibility true

Шаг 2 — открыть терминал и перейти в папку

cd ~/habitation-activity # или, если у тебя репозиторий Habitation: # cd ~/habitation/activity

Шаг 3 — установка (venv сам создастся)

chmod +x setup_linux.sh refresh-report.sh ./setup_linux.sh
Первый запуск создаёт конфиг и выходит:
~/.config/habitation/activity.json
Открой его и впиши sync_token + passphrase (те же, что на телефоне/Windows). Сохрани.

Потом ещё раз:

./setup_linux.sh

Скрипт:

  • создаст .venv (с system-site-packages — чтобы видел окна через AT-SPI)
  • поставит cryptography / matplotlib
  • включит user-service habitation-activity.service
  • запустит агент в фоне

Activate не нужен — в unit-файле уже прописан полный путь …/activity/.venv/bin/python.

Шаг 4 — проверить, что агент жив

systemctl --user status habitation-activity.service

Должно быть active (running). Логи:

journalctl --user -u habitation-activity.service -f

Строки вида uploaded 1 chunk(s) раз в ~2–3 минуты — всё ок.

Шаг 5 — красивый отчёт

Самый простой способ (venv уже внутри скрипта):

./refresh-report.sh # или за N дней: ./refresh-report.sh 14

Эквивалент без activate:

.venv/bin/python viewer/report.py --config ~/.config/habitation/activity.json --days 1

Откроется браузер с графиками. Файл лежит здесь:

~/.local/share/habitation-activity/report.html

Этот HTML статичный. Прошло два часа — снова запусти ./refresh-report.sh, не смотри вчерашнюю вкладку.

Если хочешь всё-таки activate

cd ~/habitation-activity # или ~/habitation/activity source .venv/bin/activate python viewer/report.py --days 1 deactivate # когда закончил

На работу фонового агента это не влияет. Агент уже крутится через systemd.

Полезные команды Linux

# перезапуск агента systemctl --user restart habitation-activity.service # остановить systemctl --user stop habitation-activity.service # принудительно залить буфер сейчас .venv/bin/python agent/run.py --config ~/.config/habitation/activity.json --upload

Windows

Пошагово, без «понимания командной строки». Скопировал → вставил → Enter.

Скачать

Скачать ZIP для Windows Инструкция текстом

Распакуй ZIP в папку %USERPROFILE%\habitation-activity.

Шаг 1 — Python

  1. Скачай Python: python.org/downloads/windows
  2. На установщике поставь галочку Add python.exe to PATH.
  3. Жми Install Now.

Шаг 2 — открыть чёрное окно

  1. Клавиша Windows → набери cmd → Enter.
  2. Вставь команду перехода в папку и Enter:
cd %USERPROFILE%\habitation-activity

Шаг 3 — установка

setup_windows.bat

Если откроется Блокнот с настройками — впиши тот же sync_token и passphrase, что на Linux и в Habitation. Сохрани (Ctrl+S), закрой блокнот и снова запусти setup_windows.bat.

Activate не нужен. Батники сами зовут .venv\Scripts\python.exe.

Шаг 4 — отчёт

report.bat

Откроются графики в браузере. Данные расшифровываются только у тебя.

Что делает агент

  • Смотрит активное окно и idle (отошёл ли ты).
  • Раз в ~2–3 минуты шифрует кусок лога и заливает на messenger.banderdog.com.
  • Сервер не читает содержимое — только ciphertext.
  • Телефон Habitation (Ещё → Компьютер → Sync) подтягивает отчёт.

Не публикуй passphrase. Без него отчёты не восстановить.
