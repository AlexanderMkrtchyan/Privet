Habitation Activity для Windows
================================

Это нужно, чтобы Windows сама записывала, чем ты занят за компьютером,
шифровала это и отправляла на сервер. На телефоне Habitation покажет отчёт.

Ничего «хакерского» вводить не надо — просто копируй команды по шагам.


ШАГ 0. Что скачать заранее
--------------------------
1) Python для Windows (официальный):
   https://www.python.org/downloads/windows/
   На установщике ОБЯЗАТЕЛЬНО поставь галочку:
   [x] Add python.exe to PATH
   Потом Next → Install Now.

2) Этот ZIP (habitation-activity-windows.zip) уже лежит рядом со страницей
   инструкций. Распакуй его, например, в:
   C:\Users\ТВОЁ_ИМЯ\habitation-activity\


ШАГ 1. Открыть «командную строку» (чёрное окно)
-----------------------------------------------
1) Нажми клавишу Windows на клавиатуре.
2) Набери: cmd
3) Нажми Enter.
Откроется чёрное окно. Это и есть командная строка.


ШАГ 2. Перейти в папку с программой
-----------------------------------
В чёрном окне набери (подставь свой путь, если распаковал иначе) и Enter:

  cd %USERPROFILE%\habitation-activity

Проверка: набери

  dir

Должны увидеть файлы agent, viewer, setup_windows.bat и т.д.


ШАГ 3. Установить и запустить
-----------------------------
Набери и Enter:

  setup_windows.bat

Скрипт:
- поставит нужные библиотеки Python
- спросит / создаст файл настроек
- запустит агент в фоне

Если файла настроек ещё нет — откроется блокнот с activity.json.
Впиши туда:
  "sync_token": "…тот же токен, что на Linux / в Habitation…"
  "passphrase": "…тот же длинный пароль шифрования…"
Сохрани файл (Ctrl+S), закрой блокнот, и снова запусти:

  setup_windows.bat


ШАГ 4. Посмотреть отчёт на этом же компьютере
---------------------------------------------
В том же чёрном окне:

  report.bat

Откроется красивая страница с графиками в браузере.


ШАГ 5. Чтобы агент стартовал сам после включения ПК
---------------------------------------------------
setup_windows.bat уже создаёт задачу в Планировщике заданий Windows
(имя: HabitationActivity). Проверка:

1) Windows → набери: Планировщик заданий
2) Найди HabitationActivity
3) Должно быть «Готово» / Ready


Если что-то красное в чёрном окне
---------------------------------
Скопируй текст ошибки и пришли себе в заметки. Частые причины:
- Python не в PATH → переустанови Python с галочкой Add to PATH
- Неверный sync_token / passphrase → должен совпадать с телефоном и Linux
- Нет интернета → агент копит логи локально и догонит позже


Важно про пароль
----------------
passphrase — это ключ шифрования. Сервер его не знает.
Если потеряешь passphrase — старые отчёты не расшифруешь.
