PRIVET

Messenger for web, Linux, and Windows. Open the web app now, or install a native desktop client.

Open web app Download Windows installer (.exe) Download Linux (.deb) Download Linux (.tar.gz)

Linux install (Debian / Ubuntu)

  1. Download privet-linux-amd64.deb (recommended) or the .tar.gz.
  2. Install the package: 
    sudo apt install ./privet-linux-amd64.deb
# or:
sudo dpkg -i privet-linux-amd64.deb
  3. Launch from the app menu, or run privet.
  4. Portable tarball alternative: 
    mkdir -p ~/Apps
tar -xzf ~/Downloads/privet-linux-x64.tar.gz -C ~/Apps
~/Apps/privet/privet

Native GTK desktop app (not a browser). Connects to https://messenger.banderdog.com.

Windows install

  1. Download Privet-Setup.exe.
  2. Double-click to install. If SmartScreen appears: More info → Run anyway (unsigned build).
  3. Finish the installer and launch Privet from the Start menu.

Native Flutter Windows app (not a browser wrapper). Connects to https://messenger.banderdog.com.
